# Распиновка модулей

| Модуль | Пины |
| :--- | :--- |
| **Дисплей (OLED)** | SDA: `8`, SCL: `9` |
| **Кнопки** | UP: `1`, DOWN: `2`, LEFT: `3`, RIGHT: `4`, OK: `5`, BACK: `6` |
| **Внешний разъём GPIO** | A: `10`, B: `11`, C: `12`, D: `13`, E: `14`, F: `15`, G: `16` |
| **iButton** | DATA: `15` |
| **UART** | TX: `43`, RX: `44` |
| **IR (ИК-порт)** | TX: `17`, RX: `41` |
| **SD (SPI)** | CS: `10`, MOSI: `11`, SCK: `12`, MISO: `13` |
| **CC1101 (SPI)** | CS: `7`, MOSI: `11`, SCK: `12`, MISO: `13`, GDO0: `14`, GDO2: `16` |
| **Battery** | ADC: `18`, CHRG: `21` |
